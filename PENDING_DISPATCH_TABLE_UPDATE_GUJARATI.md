# Pending to Dispatch Order - Table and Mobile Layout Update

- Desktop view now shows aligned columns: Order No., Order Date, SKU Code, Size, Dispatch, Order Qty, Details, and Cancel.
- Each pending piece remains a separate selectable row.
- Mobile view hides the wide desktop header and wraps each row into labelled, touch-friendly fields/cards.
- Dispatch and Cancel remain mutually exclusive; the existing save logic and PDF/report layouts are unchanged.
